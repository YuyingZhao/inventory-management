Filter System

1
Time Period
Month (2025-01…) or Quarter (Q1–Q4 2025). Quarter expands to 3 months server-side.
2
Warehouse
San Francisco · London · Tokyo. Matched against item.warehouse exact string.
3
Category
Circuit Boards · Sensors · Actuators · Controllers · Power Supplies. Case-insensitive match.
4
Order Status
Delivered · Shipped · Processing · Backordered. Orders endpoint only.

State Management — Composables

useFilters.js
selectedPeriod — month or quarter (ref, default 'all')
selectedLocation — warehouse ref
selectedCategory — category ref
selectedStatus — order status ref
getCurrentFilters() — returns plain object for API call
hasActiveFilters — computed boolean
resetFilters() — clears all refs to 'all'
Singleton: same instance shared across all views
useI18n.js
currentLocale — 'en' or 'ja' (ref)
currentCurrency — computed (USD / JPY)
t('key.path') — nested key lookup with fallback
translateProductName()
translateCustomerName()
translateWarehouse()

Data Files — server/data/

inventory.json
~20 items. SKU, name, category, warehouse, quantity_on_hand, reorder_point, unit_cost.
orders.json
100+ orders (2025-01–2025-09). Line items, status, warehouse, total_value, dates.
demand_forecasts.json
Per-SKU current vs. forecasted demand. Trend: increasing / stable / decreasing.
backlog_items.json
Shortage records: quantity_needed, quantity_available, days_delayed, priority.
spending.json
Object with spending_summary, monthly_spending (12 months), category_spending.
transactions.json
Recent financial transactions: date, description, amount, category.
purchase_orders.json
POs for backlog fulfillment. Starts empty; created at runtime via POST endpoint.
